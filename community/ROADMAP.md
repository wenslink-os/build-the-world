# Roadmap

## Shipped in 0.1.0

Ten JavaScript labs; local CLI; browser editor; deterministic tests; separate build/repair workspaces; dependency outage model; prerequisite map; local progress; browser export; CLI badges; static deployment; offline assets.

## Next release candidates

Stricter challenge schema validation; progress import; stage-by-stage tests; prerequisite graph edges; mutation testing; richer accessibility checks; browser end-to-end CI; reference solutions hidden behind an explicit reveal.

## Research and later releases

Rust CLI and engine; Python/Go/Rust implementations; container or VM isolation; TCP protocols; filesystem and shell labs; meaningful per-workload benchmarks; optional local AI mentor; signed third-party pack manifests; classroom tooling; broader human-language support.

Build OS, browser, Docker and LLM exercises only when their scope and test contracts are credible. A thousand incomplete folders do not meet this roadmap.
