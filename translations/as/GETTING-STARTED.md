# আৰম্ভ কৰাৰ নিৰ্দেশনা

প্ৰথমে ZIP-টো extract কৰক। কম্পিউটাৰত Node.js 20 বা তাৰ নতুন সংস্কৰণ থাকিব লাগিব। `build-the-world` folder-ত terminal খুলি এই command চলাওক:

```sh
node bin/btw.mjs serve
```

Browser-ত http://127.0.0.1:4173 খোলক। এটা lab বাছি তাৰ contract পঢ়ক। Editor-ত code লিখি **Run tests** টিপক। প্ৰথমে starter code-ৰ test fail হোৱাটো স্বাভাৱিক।

**Break it** টিপিলে defect থকা code পাব। সেই code ঠিক কৰি tests পুনৰ চলাওক। আপোনাৰ আগৰ build code পৃথককৈ থাকে। **Restore build** টিপিলে সেইটো ঘূৰাই পাব।

**Export progress** ব্যৱহাৰ কৰি backup লওক। Node.js install হোৱাৰ পিছত এই project চলাবলৈ internet, paid API বা account নালাগে। Lab-বোৰ JavaScript-ত লিখা সৰু শিক্ষামূলক model। এই সংস্কৰণত সম্পূৰ্ণ operating system বা LLM build কৰা নহয়।
